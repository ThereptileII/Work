02 / TRAFFIC & INSTRUMENTS

A fuller picture.
Clearer limits.

Review available AIS traffic, vessel instruments, alerts and source health alongside the chart. Distinguish measured input from optional forecast information.

Unavailable, stale or uncertain information is represented explicitly. SmartNav is an advisory aid; it never steers the vessel or replaces your judgment.

AIS, sensors, forecasts and other integrations need their own compatible sources. Their presence in the interface does not guarantee data coverage.

03 / AN OPENCPN FOUNDATION

A fresh perspective.
A familiar foundation.

SKAGER works with a separately installed, supported OpenCPN application. Charts, routes, tracks, waypoints and connections remain in the OpenCPN profile.

Legacy provides the familiar OpenCPN interface. Safe Mode provides a recovery path if the SKAGER interface or a plugin does not start.

The planned beta targets a Windows x64 host with the Win32/x86 OpenCPN 5.12.4 application and plugin interface. Broader compatibility is not promised.

A CLEAR BOUNDARY

Awareness first. Control stays deliberate.

Hardware control is unavailable or off by default until its qualification and explicit setup requirements are met. Supported pilot functions require device identity, fresh measured feedback and separate permission. SmartNav never steers.

The beta is not approved for navigation or production use. Always keep independent navigation and recovery arrangements.

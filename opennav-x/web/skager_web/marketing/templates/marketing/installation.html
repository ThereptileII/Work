A careful start

Keep your navigation data. Know your way back.

SKAGER works alongside your existing OpenCPN installation. Start by checking the supported version and making an independent backup.

Public downloads are closed

The beta is still being qualified. The complete installation, update, repair, rollback and uninstall lifecycle, including the installed updater, remains pending qualification. This guide prepares you for a qualified release; it does not offer an installer.

Before you begin

  1. Check OpenCPN
  2. Make a backup
  3. Follow the release guide
  4. Check recovery

01 · Prerequisite

OpenCPN 5.12.4, installed separately

The supported combination is a 64-bit Windows PC with the Win32/x86 OpenCPN 5.12.4 application and plugin interface. OpenCPN is not bundled with SKAGER. A different version or modified build is not automatically supported.

Use the official OpenCPN download page or the official OpenCPN 5.12.4 release. Check About or version information after installation.

SKAGER Setup also checks the exact supported build. If it refuses the prerequisite, stop and keep the displayed information. Do not rename executables, replace files by hand or bypass the check.

02 · Preparation

Back up before making changes

  1. Back up the OpenCPN profile and charts stored separately. Keep the backup independent of the application installation folder.
  2. Close OpenCPN, SKAGER, Legacy and Safe Mode windows, including older portable copies.
  3. Make installation changes while safely stopped, with another means of navigation available.

Licensed private charts and chart subscriptions are not included. Keep chart licenses and any required plugin information available.

03 · Qualified release

Use the instructions for the exact release

When public access opens, the release page will identify the supported installer, version, recovery information and source. Select the original installed OpenCPN application when Setup asks. Read the compatibility result and keep the backup location shown by Setup.

Before relying on the installed system, check charts, routes, tracks, waypoints, connections, plugins and the source and age of instrument readings. A successful installation does not commission your boat's equipment.

04 · Recovery

Learn Legacy and Safe Mode first

Legacy opens the familiar OpenCPN interface. Safe Mode is the recovery route for startup or plugin trouble. They use the same normal navigation profile; recovery should not require deleting your navigation data.

The maintenance lifecycle is intended to change SKAGER-owned files while retaining the original OpenCPN application and navigation data. That protection still needs qualification for the public release. Follow its documented recovery options if anything fails.

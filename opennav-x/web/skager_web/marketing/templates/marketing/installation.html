Requirements & installation

Everything you need to get started.

SKAGER runs on top of OpenCPN on your Windows PC. Check the requirements, install in a few minutes, and keep your charts and routes exactly where they are.

Requirements

Operating system
64-bit Windows
OpenCPN
OpenCPN 5.12.4 for Windows (Win32 edition), installed separately from the official OpenCPN download page
Display
1280 × 800 or larger. A touch display is recommended at the helm.
Charts
Your own charts, configured in OpenCPN. Not included with SKAGER.
Instruments
Optional. Anything OpenCPN reads: NMEA 0183, NMEA 2000 through a gateway, or Signal K.
Internet
Needed to download and update SKAGER, and for forecast wind and Online AIS. Navigation works offline.

Install in four steps

  1. Install OpenCPN 5.12.4

    Download it from the official OpenCPN website, install it, open it once and check About shows 5.12.4. More detail

  2. Back up

    Copy your OpenCPN profile and any charts stored elsewhere to a USB drive or another disk.

  3. Run SKAGER Setup

    Download Setup from your account and select your OpenCPN installation when asked. Setup checks compatibility and shows exactly what it will change before it starts. Installation guide

  4. Check before you sail

    Open SKAGER, confirm your charts, routes and waypoints are there, and check each instrument shows the source and age you expect.

Install and update while moored, with another means of navigation available.

Always a way back

Legacy

Opens the classic OpenCPN interface with the same charts, routes and connections, whenever you want it.

Safe Mode

Starts with the minimum, without the SKAGER interface or optional plugins, to sort out a problem.

Clean uninstall

Removing SKAGER leaves OpenCPN, your charts, routes and waypoints in place.

# Installed startup caution and focus

`review-installed-welcome.ps1` operates only on a recent, successful normal
installed `--xnav`, `--legacy` or `--safe-mode` launch. It requires the exact
launch result/hash, expected commit, currently owned generation, fixture-free
build report and executable hash. Stock, portable and restarted-child receipts
cannot substitute. Each action rechecks the current user/session, PID/creation
tick and complete active commissioning proof: immutable preparation/evidence,
actual plugin/helper trees, quarantined plugins and recovery copies, real profile
and input-only connections. It does not acquire authority to operate equipment.

The pinned upstream navigation caution occurs before OpenNav attaches its shell.
Its English/Swedish native structure is therefore handled by the same qualified
source-specific warning primitive, while the wrapper retains separate installed
identity and full runtime checks.

Use `-Action InspectWelcome` to capture the exact notice. If ordinary foreground
activation is denied, use the same installed launch binding with the separate
`-Action FocusWelcome`. It reuses only the fixed native warning-caption operation
from [stock coexistence review](stock-coexistence-review.md): no new coordinate,
window, key, arbitrary input or agreement capability is added. Physical DPI and
private output-directory checks remain in the installed dispatcher. The full
installed proof and exact process identity are checked before and after focus.
A changed generation/source/profile proof or an uncertain native result stops
before any successful capture. No retry occurs.

`focused-warning.png` reports `acknowledgementSent: false`. A `FocusWelcome`
result is not an inspection record and cannot authorize agreement. Run a separate
`InspectWelcome`, review its pixels and use `AcknowledgeWelcome` with that exact
record/hash only when appropriate. Both stock and installed acknowledgement now
reconstruct all writable native fields from serialized JSON and validate the
recorded derived Width/Height before the unchanged capture/intent/Agree sequence.
Other startup dialogs remain refused.

The installed policy/runtime suite passes 98 portable groups (85 policy and
13 full runtime-proof groups), including full proof mutation refusals and
explicit focus ordering checks: pre-input proof failure, changed proof after
input, reused PID, uncertain input without retry, and rejection of focus evidence
as acknowledgement. These are software policy checks; native PowerShell and an
actual installed-product notice remain distinct from actual boat acceptance.
No application or vessel hardware is touched by the portable test suite.

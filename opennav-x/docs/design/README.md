# OpenNav X Design Mockups

This directory contains the approved visual reference for the OpenNav X interface.

## Primary reference

`OpenNavX_Design_Reference.png`

Use this image as the visual target for:
- overall dark marine UI language
- chart-first composition
- top status bar
- side data panels
- contextual AIS cards
- route navigation panel
- radar overlay and radar-focus modes
- autopilot control
- sailing/instrument layout
- propulsion/energy screen
- anchor mode
- settings/connections screen

## Implementation rule

The image is a design reference, not a pixel-perfect implementation specification.

The authoritative implementation rules are in:

`OpenNavX_Codex_Project_Specification.md`

Follow the style tokens, touch target rules, data-state behavior, day/dusk/night requirements, layout rules, safety rules, and component architecture in that document.

At 1280x800, screenshots of implemented screens should be compared visually with this reference during milestone reviews.

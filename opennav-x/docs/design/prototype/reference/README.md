prototype. `linux/` contains twenty actual views/states × three themes at
1280×800, DPR1. `capture.json` records hashes, computed geometry/styles and
platform-font provenance for every screenshot.

reduced motion. On this Linux host, the prototype's fallback resolves to
Liberation Sans. **This is not Windows typography acceptance.** Native Windows
references are produced by the separate prototype CI workflow and must be
reviewed before accepting native text rendering. `windows/` now contains all
sixty native Windows reference captures from exact commit
`7925b160d90ea7892118764f848c4be63612b80e`,
[run 36442741182](https://github.com/ThereptileII/Work/actions/runs/36442741182).

Windows PNG hash match the recorded manifests. These are HTML references, not
native product conformance evidence.

All values, chart geography, radar and targets in these images come from the
immutable illustrative HTML. They are not real boat data or product screenshots.

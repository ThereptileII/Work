# Compact data-rail fit

The native compact data card keeps its full source and age metadata in its
tooltip; its accessible name continues to expose the value, unit, and quality.
Its painted number and inline unit now use measured font bounds to preserve a
four-DIP gap before the bottom status line.
Rows that are already tall enough retain the existing 48/40/33-DIP value
sizes; only a compressed row reduces the value size to keep its content above
the status line. Windows 150% visual acceptance remains pending.

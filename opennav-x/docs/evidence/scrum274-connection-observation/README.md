The existing AIS IX patch adds an owned numeric endpoint copy to the client init/Open value. Capture happens once after successful TLS/HTTP upgrade under the transport socket mutex; the base socket mutex protects the two OS queries. Address family, both numeric addresses, host-order ports, IPv6 scope IDs and steady-clock capture time are copied. No descriptor/pointer, DNS answer, credential or peer text is exposed. An unavailable observation leaves connection behavior unchanged.

The provider supplies its lifetime-scoped generation. The session publishes only after accepting Connecting→Subscribing and clears on every state outside Subscribing/Connected. No-op enables, ordinary viewport resubscription and reads preserve the original observation. Disable and credential changes invalidate callbacks and unlocked credential reads; stale results cannot initiate or relabel a new connection. Destruction clears state before joining socket threads. Retained snapshots remain owned historical values after provider destruction. Neither the tuple nor its original timestamp is a current-liveness/process-identity claim.

## White/orange derivative feasibility and constraints

The supplied prototype has no orange token. There **is** exact pinned OpenCPN provenance for the actual class: Paper lookup1947/RCID30221 has `BOYSHP4`, `COLOUR1,11`, `COLPAT1` and selects `BOYPIL81`; fallback1960/30231 omits COLPAT. Effective BOYPIL81/RCID43 is described as pillar buoy, white/orange, and uses `ADEPMDBCHBLKCCHWHTDCHCOR`. This supports using the pinned white/orange family colors without inventing a yellow classification or changing global CHCOR. Source XML locations: lookup around19962, symbol44305.

A private derivative should use only the prototype stem, small crossbar and water-filled position circle. Its exact source X is removed because the actual chart does not establish that topmark. The ordered horizontal color pattern is explicit; decorative geometry must not assert measured stripe dimensions. Keep a neutral silhouette/edge so pale white remains visible; validate the actual Day/Dusk/Night orange and white samples against real water, especially the dim stock Night orange. Failure of color recognition should retain stock, not silently substitute yellow or erase the band. A pin to the original named BOYSPP11 alone is insufficient because it also serves unknown/default shapes and many categories.

The actual NOAA records23/24 have no physical TOPMAR record; this cell has no TOPMAR layer. Their LNAM_REFS point to their two corresponding white LIGHTS objects. This proves absence of encoded topmark evidence, **not** physical absence of a topmark. Therefore omitting an invented X is conservative. Keep the independent light object/rhythm/color, object inquiry, SCAMIN, status, selection, hit testing, z-order and geographic position unchanged. Paper can still supply its existing physical portrayal.

The same private runtime-alias pattern as the qualified LIGHTS change is feasible for the exact BOYSPP variant without inserting or reordering lookup rows: verify owned instance/resources, original selected symbol, class, BOYSHP, ordered COLOUR/COLPAT and initially CATSPM27; otherwise return the stock symbol. Include both core/private renderers, negative cases for generic/default BOYSPP, yellow marks, other shapes/patterns, other tables, unknown color, and related explicit topmark data before implementation acceptance.

# Test me first

Beta 1 is for evaluation, not approved navigation.

1. Extract `OpenNavX-Beta1-Portable-win64.zip` to a short writable folder.
2. Run `Run-XNav-Demo.cmd` and confirm the DEMO banner and real chart canvas.
3. Check Navigation, Route, Energy, Instruments, AIS, SmartNav and System.
4. Try Day/Dusk/Night, data-rail presets and the stale/unavailable Demo scenarios.
5. Switch Legacy → XNav and Safe → XNav. Verify visible coastline/chart content.
6. Close it. Your installed OpenCPN profile must remain unaffected.

Before trying Setup, back up your normal OpenCPN profile and follow
`OpenNavX-Beta1-Test-Guide.md`, including its repair/rollback/uninstall sequence.
Read `KNOWN_LIMITATIONS.md` and `BUILD_INFO.md`. Keep boat control hardware
unconnected for initial desktop tests.
